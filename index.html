💡 Algorithm:
1) Raw WHS = avg(width) + adjusted height.
2) Round raw WHS (≥0.5 → up) for device matching.
3) Find ALL devices with minimal absolute difference to rounded target.
4) Filter: width ≥ avg diameter AND height ≤ aneurysm height.
5) Exclude devices where width = avg diameter OR height = aneurysm height.
6) If none, show warning.
7) Over/undersized status uses RAW WHS.
